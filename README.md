# nudge-template

The first commit of every app that nudgethis makes. nudgethis copies these files into a new repo `nudge-<name>` and puts the app name in place of `starter` in `pyproject.toml`, `app/config.py`, and `uv.lock`.

Made with `uvx stario-create@latest new starter`. To refresh it, run `just sync` and push.

## Run

```bash
just dev
```

## Check

```bash
just check
```
